Command reference

add <text>Add a task. Put @Category in it to tag it. new works too. log <text>Record something you did, at the current time. did works too. done <#>Complete a task by its number. x works too. due <#> <when>Set a due date: today, tomorrow, fri, +3d, 2026-10-14, 10/14, or none. wait <#> <on>Park a task as waiting and say what it is waiting on. resume <#>Move a waiting task back to active. pri <#> <hi|md|lo>Set priority. sub <#> <text>Add a side task under a task. step works too. note <text>Append a line to whichever notes are open — the selected task, or the scratchpad. find <text>Filter tasks and the log. Lists
Mine is your own list, and only you see it. Family is shared: everyone who uses Home To-Do sees it and can change it. Switch between them with the buttons beside the logo. Each list has its own tasks, log and scratchpad, and its own task numbers; categories are shared by both.
Side tasks
Select a task and the notes panel gains a Side tasks list — the steps that make up the job. Each one ticks off on its own and can carry its own notes, opened with the ≡ button beside it. In the task list they fold away behind the 2/5 counter; click it to show or hide them. They follow the task into the completed log.
Top bar shortcuts
Shortcut links appear in the top bar once you add some under Settings, in the menu beside the clock. Each one opens its web address in a new tab.
Categories
Tag a task or log entry with a category from the picker, or with @Name in the command bar — add @Category fix the printer.
Spaces, underscores and case are all ignored when matching, so Back_Yard, back_yard, backyard and back yard all reach Back Yard. @Name also accepts a unique prefix (@back) and is the only way to create a category from the command bar — @Back_Yard is stored as Back Yard.
While you type an @tag, the command bar completes it — press Tab or → to accept the greyed-out ending.
Shorthand
! at the start of a task sets high priority — add !water heater is leaking.
^friday or ^+2d in an add sets the due date inline.
Keyboard
Ctrl KJump to the command bar. EscClose a dialog, or deselect the open task. Light / darkFollows Home Assistant's own setting. Double-clickRename a task or log entry in place.
Notes follow the selection. Click any task to open its own notes in the right panel; the detail bar above them edits due date, priority, category and waiting status. Close the task tab to return to the shared scratchpad. Notes stay attached when a task is completed.
Everything is saved in Home Assistant as you go, so every device you sign in on shows the same lists. The pill beside the clock says Saved once Home Assistant has it.
